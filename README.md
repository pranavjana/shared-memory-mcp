# Shared Memory MCP

A two-person GraphHacks Track 2 project for shared personal memory across assistants, with FalkorDB planned as the central memory store.

## Status

Workspace setup only. Implementation has not started. The project owner will build the implementation in Codex.

## First milestone

Build an MCP server with `remember`, `recall`, and `update` operations. These are planned capabilities; no features or client integrations have been implemented or verified.

Proactive notifications are future work.
